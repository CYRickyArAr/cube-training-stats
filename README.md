# 魔方训练统计

腾讯文档为唯一成绩来源。GitHub Actions 定时完整读取、移除文档定位信息后，发布只读统计快照到 GitHub Pages。

## 公开范围

网页、训练人员名称和成绩是公开数据；拿到网址的人可以查看和下载。本站没有访问控制。腾讯文档地址、文档 ID、工作表 ID、访问凭据不进入代码、成绩 JSON 或 Pages 产物。

仓库 Secret `SOURCE_CONFIG` 保存私有来源配置，仅定时读取步骤可用。不要提交来源配置、旧工程备份、源表测试快照或读取器运行目录。

## 更新

Actions 每 30 分钟读取一次（调度可能延迟），也可在 Actions 手动运行。浏览器每 60 秒检查已发布快照；“刷新快照”不会触发源表读取。页面展示成绩更新时间，超过 60 分钟标记为旧快照。

读取失败、不完整、空快照、隐私检查失败都中止发布，保留上次成功站点。GitHub 可能暂停长期无活动仓库的定时工作流；如无更新，请检查 Actions 并重新启用。

## 统计

每条数据为源表已经计算的 ao5。Sub7 为严格小于 7 秒的组数 / 当前范围总组数，DNF 算未达标。保留源表精度、日期、DNF、有效值和异常警告。近期分析比较最近 20 条与此前 20 条有效 ao5 的均值，需要至少 40 条有效记录；DNF 不占有效样本名额。

## 验证

Node 22 或更新版本：`node --test tests/*.test.cjs`。
发布脚本只在环境变量 `SOURCE_CONFIG` 中读取私有配置，通过 Windows Edge 读取完整源表。只有 `dist/` 白名单文件作为 Pages 发布产物；仓库根目录不直接发布。
