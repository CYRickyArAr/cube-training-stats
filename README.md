# 魔方训练统计

统计范围支持全部、最近 7/30/90 天和「指定日期」。选择指定日期后直接弹出页面日历，默认定位最近有日期的训练日；点击日期立即更新统计但不关闭日历，可连续选日期，点击日历外或按 Esc 才收起。支持上下月、方向键、清除和今天；有训练记录的日期带圆点。切换人员、对比或刷新时保留所选日期。当天无成绩就显示无记录，不混入其他日期。同一标签页刷新或强制刷新后保留统计范围和所选日期；sessionStorage 仅保存这两项筛选偏好，不保存人员、成绩或腾讯快照。

腾讯文档为唯一成绩来源。GitHub Actions 定时完整读取、移除成绩中的文档定位信息后，发布只读统计快照到 GitHub Pages。顶部提供「打开腾讯文档」，新标签页打开源表。

## 公开范围

网页、训练人员名称和成绩是公开数据；拿到网址的人可以查看和下载。本站没有访问控制。经所有者授权，Pages 页面的「打开腾讯文档」按钮公开文档地址（因此文档 ID 也可见）；访问和编辑权限由腾讯文档共享设置控制。按钮只保留 https://docs.qq.com/sheet/ 下的文档路径，移除全部查询参数和片段，包括 rtkey、工作表 ID 和跟踪参数。仓库代码仍不硬编码实际链接，成绩 JSON 仍不含文档地址或内部 ID，访问凭据与私有来源配置不进入发布产物。

仓库 Secret `SOURCE_CONFIG` 保存私有来源配置，仅定时读取步骤可用。不要提交来源配置、旧工程备份、源表测试快照或读取器运行目录。发布时从该配置派生不含凭据的按钮链接，隐私检查仅豁免按钮的这一个 href；其他位置仍禁止出现私有来源信息。按钮无法绕过腾讯权限；如匿名访客无法打开，请检查腾讯文档分享权限。

## 更新

Actions 每 30 分钟读取一次（调度可能延迟），也可在 Actions 手动运行。JS/CSS 使用内容哈希版本号，页面更新后不会沿用旧版资源缓存。浏览器每 60 秒检查已发布快照；“刷新快照”不会触发源表读取。读取状态、成绩更新时间和自动同步开关显示在顶部导航栏，不占统计主内容；窄屏时在顶部换行。快照超过 60 分钟标记为旧快照。

读取失败、不完整、空快照、隐私检查失败都中止发布，保留上次成功站点。GitHub 可能暂停长期无活动仓库的定时工作流；如无更新，请检查 Actions 并重新启用。

## 统计

每条数据为源表已经计算的 ao5。Sub7 为严格小于 7 秒的组数 / 当前范围总组数，DNF 算未达标。保留源表精度、日期、DNF、有效值和异常警告。近期分析比较最近 20 条与此前 20 条有效 ao5 的均值，需要至少 40 条有效记录；DNF 不占有效样本名额。

多人对比新增「累计比分」：当前人员列表全部参赛，源表同一行、同一日期作为一局，只有全部人员有成绩（含 DNF）的完整局计分。N 人第 r 名得 N − r 分，3 人 2/1/0，2 人 1/0；并列名次同分、后续名次跳过（3 人并列第一各 2 分，下一名第 3 得 0 分），DNF 始终 0 分。缺成绩、异常或重复来源的局跳过，按原始精度排名，不凑各人的第几条记录。计分局数和跳过局数可见，无完整局显示「—」。比分随统计范围筛选，不改变均值排序，不写回源表。

## 验证

图表支持「趋势 / 分布」原位切换，切换人员、日期或刷新后保留模式。趋势图最多绘制最近 120 组；分布图覆盖当前筛选范围全部有效 ao5，每档 0.10 秒：6.00–6.09 表示 6.00 ≤ 用时 < 6.10，按原始精度分桶、不先四舍五入。DNF 单独计数，不进入用时柱；悬停可查看组数与占有效组比例。跨度超过 160 档时标记并省略长段空档，但不删除或合并任何有效值；整体分布自适应图表宽度，无需横向滚动。每个绘制区间都显示起点刻度（如 6.0 表示 6.00 ≤ 用时 < 6.10）；刻度密集时分行错开，必要时增加图表高度，不跳过标签。柱顶数字过密时不绘制，悬停仍可查看完整区间与组数。

界面交互、样式和统计逻辑与本地版一致，仅数据读取方式及对应说明不同。本地工程通过 `node sync-online.cjs` 生成此目录的共用文件，提交前用 `node sync-online.cjs --check` 校验同步，避免手工修改产生差异。

Node 22 或更新版本：`node --test tests/*.test.cjs`。
发布脚本只在环境变量 `SOURCE_CONFIG` 中读取私有配置，通过 Windows Edge 读取完整源表。只有 `dist/` 白名单文件作为 Pages 发布产物；仓库根目录不直接发布。
