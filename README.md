# 魔方训练统计

统计范围支持全部、最近 7/30/90 天和「指定日期」。选择指定日期后直接弹出页面日历，默认定位最近有日期的训练日；点击日期立即更新统计但不关闭日历，可连续选日期，点击日历外或按 Esc 才收起。支持上下月、方向键、清除和今天；有训练记录的日期带圆点。切换人员、对比或刷新时保留所选日期。当天无成绩就显示无记录，不混入其他日期。同一标签页刷新或强制刷新后保留统计范围和所选日期；sessionStorage 仅保存这两项筛选偏好，不保存人员、成绩或腾讯快照。

腾讯文档为唯一成绩来源。GitHub Actions 定时完整读取、移除成绩中的文档定位信息后，发布只读统计快照到 GitHub Pages。顶部提供「打开腾讯文档」，新标签页打开源表。

## 公开范围

网页、训练人员名称和成绩是公开数据；拿到网址的人可以查看和下载。本站没有访问控制。经所有者授权，Pages 页面的「打开腾讯文档」按钮公开文档地址（因此文档 ID 也可见）；访问和编辑权限由腾讯文档共享设置控制。按钮只保留 https://docs.qq.com/sheet/ 下的文档路径，移除全部查询参数和片段，包括 rtkey、工作表 ID 和跟踪参数。仓库代码仍不硬编码实际链接，成绩 JSON 仍不含文档地址或内部 ID，访问凭据与私有来源配置不进入发布产物。

仓库 Secret `SOURCE_CONFIG` 保存私有来源配置，仅定时读取步骤可用。不要提交来源配置、旧工程备份、源表测试快照或读取器运行目录。发布时从该配置派生不含凭据的按钮链接，隐私检查仅豁免按钮的这一个 href；其他位置仍禁止出现私有来源信息。按钮无法绕过腾讯权限；如匿名访客无法打开，请检查腾讯文档分享权限。

## 更新

Cloudflare Worker 每 5 分钟触发 GitHub Actions，读取腾讯文档并发布；已有工作流未完成时跳过本轮。GitHub 自带定时器改为每小时第 43 分钟兜底（仍可能延迟或漏触发），也可在 Actions 手动运行。Cloudflare 首次 Cron 配置传播可能需约 15 分钟；触发、runner 排队、读取和部署均可能延迟，不保证每 5 分钟准点完成。部署与令牌维护见 [Cloudflare 定时器说明](automation/cloudflare/README.md)。JS/CSS 使用内容哈希版本号，页面更新后不会沿用旧版资源缓存。浏览器每 60 秒检查已发布快照；“刷新快照”不会触发源表读取。读取状态、成绩更新时间和自动同步开关显示在顶部导航栏，不占统计主内容；窄屏时在顶部换行。快照超过 60 分钟标记为旧快照。

读取失败、不完整、空快照、隐私检查失败都中止发布，保留上次成功站点。如无更新，先检查 Cloudflare Worker 日志、`GITHUB_TOKEN` 是否过期及 Actions 运行结果。GitHub 可能暂停长期无活动仓库的原生定时工作流；需要时重新启用兜底调度。

## 统计

个人分析以「P90 ao5」和「最长连续 Sub7」替代 DNF 占比，原有 DNF 组数保留。P90 将全部有效用时按原始精度升序排列，取第 ⌈0.9 × 有效组数⌉ 项（最近秩法），至少 90% 的有效 ao5 不超过它；不足 10 组提示仅供参考，无有效成绩显示「—」。最长连续 Sub7 按当前人员和范围内的日期、源行号顺序计算，可跨日；未知日期排在已知日期前，DNF 或 ≥7 秒中断，6.999 秒仍达标。无记录显示「—」，有记录但无 Sub7 显示 0 组。两项均统计全部筛选记录，不限于趋势图的最近 120 组。

每条数据为源表已经计算的 ao5。Sub7 为严格小于 7 秒的组数 / 当前范围总组数，DNF 算未达标。保留源表精度、日期、DNF、有效值和异常警告。日均变化比较同一人员本次与上一次训练日各自全部有效 ao5 的均值，不截取固定组数；例如当天 20 局、上次 15 局，分别使用各天全部有效成绩，DNF 不参与均值。指定日期以所选日为本次，其他范围以范围内最新训练日为本次；从该人员全部历史找此前最近有记录的一天，可在筛选范围外。跳过没练的日期，不跳过全 DNF 的训练日；缺少上次训练或任一天无有效成绩时提示无法比较。提升率 =（上次均值 − 本次均值）÷ 上次均值，按原始精度计算。其他指标与历史表仍严格使用当前筛选范围。

多人对比新增「累计比分」：每天有成绩（含 DNF）的人员实际参赛，缺席者不占名额并显示「—」。源表同一行、同一日期作为一局；只有当天全部参赛者都有成绩的完整局计分。全部或最近天数范围按每一天实际人数分别计分后累计。N 人第 r 名得 N − r 分，3 人 2/1/0，2 人 1/0；并列名次同分、后续名次跳过（3 人并列第一各 2 分，下一名第 3 得 0 分），DNF 始终 0 分。缺成绩、异常或重复来源的局跳过，按原始精度排名，不凑各人的第几条记录。计分局数和跳过局数可见；每人无参赛完整局时显示「—」，参赛但未得分显示 0。比分随统计范围筛选，按累计比分从高到低排序；同分按有效 ao5 均值从低到高，再按姓名排序，无比赛比分（—）排在最后，0 分排在无比分者之前。不写回源表。

## 验证

图表支持「趋势 / 分布」原位切换，切换人员、日期或刷新后保留模式。趋势图最多绘制最近 120 组；分布图覆盖当前筛选范围全部有效 ao5，每档 0.10 秒：6.00–6.09 表示 6.00 ≤ 用时 < 6.10，按原始精度分桶、不先四舍五入。DNF 单独计数，不进入用时柱；悬停可查看组数与占有效组比例。跨度超过 160 档时标记并省略长段空档，但不删除或合并任何有效值；整体分布自适应图表宽度，无需横向滚动。每个绘制区间都显示起点刻度（如 6.0 表示 6.00 ≤ 用时 < 6.10）；刻度密集时分行错开，必要时增加图表高度，不跳过标签。柱顶数字过密时不绘制，悬停仍可查看完整区间与组数。

界面交互、样式和统计逻辑与本地版一致，仅数据读取方式及对应说明不同。本地工程通过 `node sync-online.cjs` 生成此目录的共用文件，提交前用 `node sync-online.cjs --check` 校验同步，避免手工修改产生差异。

Node 22 或更新版本：`node --test tests/*.test.cjs`。
发布脚本只在环境变量 `SOURCE_CONFIG` 中读取私有配置，通过 Windows Edge 读取完整源表。只有 `dist/` 白名单文件作为 Pages 发布产物；仓库根目录不直接发布。
