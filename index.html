Sub7 率 = ao5 严格小于 7 秒的组数 / 当前范围总组数；7.00 秒不达标，DNF 计入总组数但不达标，按源表原始精度判断。每条是一组已计算的 ao5。DNF 不参与均值、中位数、P90 和标准差；异常大值仍计入统计。P90：将有效用时从小到大排列，取第 ⌈0.9 × 有效组数⌉ 个，至少 90% 的有效 ao5 不超过该用时；不足 10 组仅供参考。最长连续 Sub7：在当前人员、当前范围内，按训练日期、源表行号依次计算，可跨日；DNF 或 ≥7 秒中断，按原始精度判断。暂无记录显示「—」，有记录但无 Sub7 显示 0 组。日均变化比较该人员本次与上一次有训练记录的日期，各自全部有效 ao5 的均值，不截取固定组数；DNF 不参与均值，任一天没有有效成绩时不比较，也不跳过全 DNF 的上次训练。指定日期以所选日为本次，其他范围以范围内最新训练日为本次；对照日可在筛选范围外，中间未训练的日期自动跳过。提升率 =（上次均值 − 本次均值）÷ 上次均值；样本量不同请谨慎比较。标准差 ÷ 均值为波动系数，样本少时谨慎解读。除日均变化的上次训练对照外，指定日期只统计当天源表成绩；未知日期不补成今天，也不计入日期筛选。

比分规则

按每天实际有成绩（包括 DNF）的人员确定参赛人数，缺席者不占名额，比分显示「—」。源表同一行、同一日期视为一局；全部或最近天数范围按各天实际人数分别计分后累计。完整局按用时从快到慢排名，N 人第 r 名得 N − r 分：3 人为 2 / 1 / 0，2 人为 1 / 0。并列名次同分，后续名次顺延跳过（3 人并列第一各得 2 分，下一名第 3 得 0 分）；DNF 始终得 0 分。当天参赛者在某一行缺成绩，该局不计分；不按各人的第几条记录凑局。没有完整局时比分显示「—」。按累计比分从高到低排序；同分按有效 ao5 均值从低到高，再按姓名排序。无比赛比分（—）排在最后。
